🧩 LEVEL 1 TASK SYSTEM (SELECTION-FIRST)

I’ll give you task archetypes, not just examples, so this scales.

1. Ranking Together (Drag & Drop)

Core mechanic: reorder items to agree on a final list.

Examples

Rank 6 weekend activities from “most relaxing” to “least”

Rank snacks for a movie night

Rank superpowers by usefulness in daily life

Why this works

Zero typing

Natural disagreement → collaboration

You learn how someone thinks without asking

UX detail:

Each user drags privately

App reveals differences

Final ranking is built together

Shared memory is born here.

2. Constraint-Based Selection

Core mechanic: pick X items under a rule.

Examples

Pick 3 songs for a 15-minute commute

Choose 4 items to survive a night outdoors

Pick 5 apps to keep if you could only have 5

Why it works:

Scarcity forces discussion without chat

Everyone feels involved

No right answer

Even better in micro-groups.

3. Either / Or Chains

Core mechanic: binary choices that converge.

Examples

Coffee vs Tea

Mountains vs Beach

Early morning vs Late night

After 8–10 choices:

“Here’s what your group aligned on”

This gives:

instant bonding

pattern recognition

“oh, we’re similar” moments

No one spoke. Still connected.

4. Collaborative Sorting

Core mechanic: sort cards into buckets.

Examples

Buckets:

“Must-have”

“Nice-to-have”

“Skip”

Cards:

Travel items

Hobbies

Daily habits

Weekend plans

Each user sorts, then merges.

This feels productive, not social. That’s the trick.

5. Visual Puzzles (Shared Board)

Core mechanic: manipulate objects together.

Examples

Untangle a shared node graph

Match symbols under time pressure

Arrange shapes to complete a pattern

Why this is powerful:

Immediate team feeling

No social comparison

Pure cooperation

This mirrors online games where friendships quietly form.

6. “Build a Thing” Without Words

Core mechanic: assemble something visually.

Examples

Build a mood board for “cozy evening”

Assemble a simple routine timeline

Design a fictional room layout

Each person controls part of the board.

No text. Still expressive.
