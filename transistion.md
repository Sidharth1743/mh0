1. The Transition Trigger (NOT time-based)

Never unlock Level 2 just because a task finished.

Unlock it when patterns emerge.

Safe unlock signals

Pick 2–3 of these:

Completed 2 tasks together

Alignment score ≥ X% (e.g. 6/10 matches)

No drop-offs or abandons

Same group rematched

This tells users:

“This is earned, not random.”

2. The Psychological Reframe

Don’t frame Level 2 as chat.

Frame it as:

“React”

“Add context”

“Leave a note on the task”

Language matters more than features here.

❌ “Start chatting”
✅ “Add a quick reaction to this task”

3. The First Text Is Constrained (Crucial)

Level 2 never opens a blank chat box.

It opens task-bound micro-expression.

First interaction types
A. Sentence Starters (Tap-to-fill)

Users tap one of these and optionally tweak it:

“I liked that we agreed on ___”

“That choice surprised me”

“This felt easy / tricky”

“I’d do this again”

Typing is optional, not required.

B. Emoji + One-Line Limit

Max 120 characters

Emoji-first UI

One message per user per task

This prevents:

rambling

oversharing

pressure to perform

C. Reaction-to-Artifact

They react to the result, not each other.

Example:

Tap on a ranked list item and comment

React to the final board

This keeps focus external.

4. The UI Moment (Very Important)

Do NOT auto-open chat.

Instead show a gentle card:

“You’ve completed 2 tasks together
Want to add a reaction?”

Two buttons:

“Skip for now”

“Add a reaction”

Skipping never penalizes.

5. The First Message Is Ephemeral

This is a trust accelerator.

First reactions fade after 24 hours

Or are tied only to the task

This lowers fear:

“This isn’t permanent. I can test the water.”

Later levels make things persistent.

6. The Second Task Changes Slightly

Level 2 tasks include reflection hooks, but still no deep sharing.

Examples:

After ranking: “Which item was hardest to agree on?”

After puzzle: “What slowed us down?”

These appear as tap-to-select, not text.

7. Reinforce Safety Visually

After first reaction, show subtle reassurance:

“No profiles yet”

“You control what you share”

“Names stay hidden”

Trust grows when safety is visible.

8. The Exit Is Always Obvious

At any point:

“Return to tasks”

“Mute reactions”

No social trap doors.

🧠 THE CORE RULE (WRITE THIS ON A WALL)

Level 2 is not about talking more.
It’s about adding meaning to what already happened.

If conversation drifts away from tasks, pull it back.
